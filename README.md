## Install

```bash
git clone https://github.com/afeezadebayo/ai-workflows-automation-skills.git
# Claude Code
cp -r ai-workflows-automation-skills/ai-workflow-audit ~/.claude/skills/
# Codex and other agents
cp -r ai-workflows-automation-skills/ai-workflow-audit ~/.agents/skills/
```

In Claude.ai or Claude Desktop, zip a single skill folder and upload it under **Settings → Capabilities → Skills**.
